## Description de l'Œuvre
DASS est une plateforme SaaS (Software as a Service) destinée à la recherche médicale, intégrant :
1.  Un générateur de formulaires dynamiques (Form Builder) avec logique conditionnelle.
2.  Un module d'analyse statistique assisté par Intelligence Artificielle (Intégration Gemini).
3.  Un système de micro-transactions (Wallet & Coins) pour la monétisation des services.
4.  Une place de marché (Bibliothèque) pour l'échange de propriété intellectuelle entre étudiants.

## Actifs Protégés
L'ensemble des éléments suivants constitue l'actif incorporel de la société JS GATE :
*   Le code source complet (Frontend React/TypeScript).

*   Les algorithmes de "Prompt Engineering" utilisés pour l'analyse médicale.
*   L'identité visuelle et l'interface utilisateur (UI/UX).
